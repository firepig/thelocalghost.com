Polter Is Live

Design Dev Release

After months of late nights, hundreds of test runs, and more regex than any human should write in a lifetime — Polter is shipping.

Polter is a desktop file automation tool. You set rules, it organizes your files. That's it. No cloud sync, no subscription, no accounts, no nonsense.

Why we built it

Everyone has a downloads folder that looks like a crime scene. Screenshots, PDFs, zip files, installers — all piling up until you can't find anything. We tried existing tools and they were either too complex, too expensive, or wanted to upload everything to someone else's server.

So we built our own. Polter watches folders and applies rules you define. Move files by name pattern, extension, date, size — whatever makes sense for your workflow. It runs quietly in the background and just... handles it.

What makes it different

  • Runs locally. Your files never leave your machine.
  • One-time purchase. $24, lifetime. No monthly fees, no "pro" tier.
  • Cross-platform. Windows, macOS, and Linux — same experience everywhere.
  • Simple rules engine. No scripting required. Point, click, done.
  • Lightweight. Sits in your system tray using minimal resources.

What's next

This is v1.0 — the foundation. We're already working on regex support for power users, folder pair rules, and conditional chaining for more complex workflows. If there's something you want to see, tell us.

Polter is the first of several small, focused tools we have planned. Each one solves a specific problem well, with the same philosophy: local-first, one-time pricing, no bloat.

Ready to clean up your files?

Polter is available now for Windows, macOS, and Linux. One-time purchase, lifetime access.
